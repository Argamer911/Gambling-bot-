# 🎮 GAMBLING UNIVERSE

An advanced Telegram gaming bot project with virtual coins, XP, player profiles, leaderboards and a Telegram Mini App.

## Current starter features
- /start — create a player profile
- /help — show commands
- /games — show the original 15-game catalog
- SQLite player database
- Environment-variable configuration

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Create a local `.env` file using `.env.example`.
3. Add your Telegram bot token to `.env`.
4. Run: `python Main.py`

All coins are virtual game points only. No real-money betting, deposits, purchases or cash withdrawals are supported.
